## Proyecto BioLink ##

## Estructura del proyecto ##

- cliente: React.js + TailwindCSS
- servidor: Django Rest Framework.
- base de datos: MySQL + Microsoft Workbench para desarrollo.
- model.mwb -> es el archivo de modelado gráfico de bd para Workbench.
- base_de_datos_script.sql -> Es el script que genera la bd.

## ¿Cómo ejecutar el proyecto? ##

0. Debes tener abierto Docker Desktop (obligatorio).
1. Para facilitar la ejecución, descarga la extensión "Restore terminales" de VSCode. 
2. Presiona ctrl + shift + p 
3. Escribe "Restore terminals" (quizá ya te salga sin buscarlo).
4. Los comandos necesarios para ejecutar el proyecto se ejecutarán enseguida.
