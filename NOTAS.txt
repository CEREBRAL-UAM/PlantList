

-------------- Opciones para la base de datos ---------------

1. Ajustar los modelos de django para que coincidan con la bd actual 

    Pros: No alteramos la bd original

    Contras: 
        * Se pierden campos y relaciones importantes dentro de Plantlist.
        * Habrá que resideñar de nuevo gran parte de la lógica de Plantlit 
          para matchear al 100 con la base de datos original.

2. Agregar campos y relaciones faltantes

    Pros: Plantlist tendrá todo lo necesario para servir 

    Contras: 
      * Alteramos la base de datos original
      * Habrá que resideñar de nuevo buena parte de la lógica de PlantList para 
        matchear al 100 con la base de datos original (aún a pesar de que ya 
        tenga los campos nuevos).
         

3. Crear una capa de traducción  (LA CHIDA)

    Pros:
        * Tanto Plantlist como la bd original pueden funcionar de forma independiente.
        * El sistema puede tener los campos y relaciones que necesite sin importar 
          que estos no se encuentren en la bd original.

    Contras: 
        * Aumenta la cantidad de código (ya que habrá que crear serializadores
          para cada tabla).
